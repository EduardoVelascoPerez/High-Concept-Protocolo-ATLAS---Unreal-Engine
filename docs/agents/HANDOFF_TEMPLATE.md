# Modelo obrigatório de handoff

Copie a estrutura abaixo na mensagem final da tarefa. Não omita campos; use
`não executado` ou `nenhum` quando necessário.

```markdown
## Handoff <ID da tarefa>

- Responsável:
- Branch:
- Estado final:
- Commit(s):
- Objetivo atendido:

### Arquivos alterados

- `<caminho>` — motivo

### Validações executadas

- `<comando>` — resultado

### Reservas de ativos

- Criadas:
- Liberadas:
- Ainda ativas:

### Riscos e limitações

- ...

### Próxima ação recomendada

- ...
```

Não afirme que um Blueprint compila ou que um fluxo funciona no Unreal sem ter
aberto a versão correta do editor e realizado o teste correspondente.
